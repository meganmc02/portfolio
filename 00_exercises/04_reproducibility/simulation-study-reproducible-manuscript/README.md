# my-reproducible manuscript

<!-- badges: start -->
<!-- badges: end -->

The goal of my-reproducible-manuscript is to investigate the impact of measurement error in linear regression analysis.

Random noise is added to an exposure variable and/or a confounding variable in a multivariable linear regression. The noise is drawn from a normal distribution with mean 0 and variance ranging from 0% to 50% (of the variable’s variance), representing measurement error in the variables.

The resulting bias in the estimated effect is then assessed.
